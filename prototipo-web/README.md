# Prototipo web admin — Distribuidora

Doble click en `index.html` para empezar. Navegá con el sidebar.

Este prototipo es una maqueta visual estática para validar pantallas y flujos con las personas interesadas. Todos los datos están cargados directamente en HTML; los formularios, filtros, botones y gráficos son representaciones visuales y no ejecutan lógica real.

La interfaz utiliza Tailwind CSS v4 mediante CDN y un pequeño archivo `estilos.css` compartido. Se recomienda abrirla con conexión a internet para que cargue Tailwind desde el CDN.

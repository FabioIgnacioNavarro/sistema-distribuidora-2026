# Prototipo web admin — Distribuidora

Doble click en `index.html` para empezar. Navegá con el sidebar.

Este prototipo es una maqueta visual para validar pantallas y flujos con las personas interesadas. Todos los datos están cargados directamente en HTML; los formularios, filtros y gráficos siguen siendo representaciones visuales. La navegación lateral, sus desplegables, los detalles de tablas, la posición de la barra y el cambio de tema sí cuentan con interacción local para facilitar la revisión.

La interfaz utiliza Tailwind CSS v4 mediante CDN y un pequeño archivo `estilos.css` compartido. Incluye modo oscuro automático: sigue la preferencia de tema configurada en el sistema operativo o navegador. Se recomienda abrirla con conexión a internet para que cargue Tailwind desde el CDN.

# Admin web

Aplicación web de administración de la distribuidora.

## Stack definido

- React
- Vite
- Tailwind CSS

El admin es una aplicación cliente independiente. Consume la API Fastify del monorepo y no utiliza Next.js.

La maqueta visual de referencia está en [`prototipo-web`](../../prototipo-web/README.md).

## Desarrollo

El proyecto se ejecutará con los scripts definidos en el workspace raíz usando `pnpm`. La implementación de las pantallas y la configuración de Vite quedan pendientes de la migración del starter actual.

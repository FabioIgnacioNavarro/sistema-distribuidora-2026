# Prototipo móvil del vendedor

Maqueta estática del flujo principal del vendedor:

1. Elegir cliente y productos.
2. Revisar el remito antes de confirmar.
3. Confirmar el pedido y consultar el historial.

Abrir `index.html` directamente en el navegador o servir esta carpeta con cualquier servidor estático. La implementación final vivirá en `apps/movil` con Expo; esta carpeta no agrega dependencias ni reemplaza la app nativa.
